Adaptive Traffic Light Simulation

Python, SUMO, TraCI

My final-year project: a simulation that compares a standard fixed-timer traffic light system against a density-based adaptive algorithm. The adaptive system reads live traffic density from the simulation and adjusts signal timing accordingly, with a three-level priority system that can also grant precedence to emergency vehicles.

What it taught me: working with simulation environments and real-time decision logic, and thinking carefully about how a system should behave under competing priorities rather than a single fixed rule.

Mental Health Support System

Java, Spring Boot, MySQL

A backend-focused academic project built to support users seeking mental health resources and guidance, structured around a Spring Boot API with a MySQL database. The goal was a system that could reliably manage user data and support content while staying straightforward to extend.

What it taught me: structuring a Spring Boot application properly, and designing a database schema for a domain that has to be handled carefully and accurately.

Email Automation System

Python, APIs, Scripting

Built during my internship at Rwanda Airports Company (RAC): a system that automated recurring email workflows, cutting out manual, repetitive sending and formatting so the team could focus on higher-value work. Covered templating, scheduling, and reliable delivery of routine communications.

What it taught me: how much time a small piece of automation can save in a real organization, and how to design a script that others on the team could trust and reuse without babysitting it.
